近年来，越来越多的中国专业人士到阿联酋、沙特阿拉伯、卡塔尔、科威特、巴林和阿曼工作。基础设施和建筑、能源、通信、电商、物流、制造、酒店和金融等行业，都有大量中资企业和国际公司在当地招聘。除了在中资企业内部外派之外，也有不少人直接向当地公司或跨国企业投递简历。可是一份在北京或深圳好用的中文简历，投到迪拜或利雅得之前，需要做不少调整。

首先，简历几乎总是要用英文写。其次，海湾地区的雇主常常希望看到一些中国简历里不常见的信息，比如国籍、签证状态和离职通知期。再次，当地的跨国公司通常先用求职者跟踪系统（ATS）筛选简历，对个人信息的要求比本地公司少。本指南说明应该写什么、应该删掉什么，以及如何在简历中体现学历认证等手续问题。很多地区性公司也在埃及招聘，所以这些建议在埃及同样适用。需要提醒的是，不同国家、行业和公司的做法差别很大，下面的内容是常见习惯，而不是固定规则。

## 海湾求职简历一览

| 项目 | 常见做法 |
| --- | --- |
| 语言 | 私营企业用英文，部分政府机构要求阿拉伯语或双语 |
| 篇幅 | 一到两页 |
| 照片 | 本地公司常见，跨国公司可选 |
| 个人信息 | 国籍、所在地或签证状态、离职通知期，需要时注明驾照 |
| 薪资 | 不写在简历上，被问到时再说 |
| 学历 | 办理工作签证前通常需要认证，投递时一般不需要 |
| 文件 | PDF 格式，文件名包含姓名和目标职位 |

## 英文、阿拉伯语还是双语？

简历的语言应当和招聘广告一致。在阿联酋、卡塔尔和巴林，私营企业的大部分职位都用英语发布，因为团队成员来自世界各地。在沙特、科威特和阿曼，两种语言都很常见，政府机构和半官方机构更倾向于阿拉伯语。

对中国求职者来说，一份清晰的英文简历在绝大多数情况下就够了。不要把中文简历直接丢进翻译软件，生成什么就发什么。职位名称在英文里有约定俗成的说法，比如"项目经理"是 Project Manager，"总账会计"是 General Ledger Accountant，"现场工程师"是 Site Engineer。公司名称请使用其官方英文名，如果公司在海外不出名，就在后面加一句说明它是做什么的、规模多大。

如果某个职位要求阿拉伯语简历，请找精通阿拉伯语的人检查，并且两个版本的职位、日期和数字必须完全一致。阿拉伯语从右往左书写，不支持这种排版的软件会把日期颠倒、把字母拆散，看起来很不专业。

## 当地常见的个人信息

这是海湾简历和西方简历差别最大的地方。本地雇主通常希望看到这些信息，跨国公司要求较少。原则很简单：写能帮助雇主做出录用决定的信息，删掉与工作无关的内容。

| 信息 | 是否填写 |
| --- | --- |
| 国籍 | 通常要写，会影响签证办理 |
| 目前所在地和签证 | 要写，例如"迪拜，持居留签证"或"上海，可外派" |
| 离职通知期 | 要写，例如"随时到岗"或"一个月" |
| 驾照 | 如果工作需要开车就写，并注明发证国家 |
| 出生日期 | 可选，现在很多人不写 |
| 照片 | 可选，本地公司常见 |
| 婚姻状况 | 可选，如果薪酬包含家属签证可能有用 |
| 政治面貌、宗教、身份证号、护照号 | 不要写 |

中国简历里常见的政治面貌、籍贯、民族、身高体重等信息，在海湾求职简历里都没有必要。护照信息会在之后办理签证时提供，放在简历上只会让你的个人资料无谓地流转到更多人手里。

### 签证状态和所在地

海湾地区的招聘人员常常把候选人分成两类：已经在当地的人，以及需要办理新签证的人。已经持有可转签居留签证在阿联酋生活的人，有时可以更快入职。如果你在国内，请明确写出你愿意赴当地工作。各国关于担保和签证转移的规定不同，而且近几年好几个国家都有调整，所以不要在简历里写法律层面的说法，如实写明现状，细节留到面试时再谈。

### 离职通知期

在海湾地区，离职通知期根据合同通常是一到三个月。招聘方会很早问到这一点，因为它决定签证办理时间和入职日期。国内的离职流程一般是提前三十天通知，如果你能尽快到岗，这是实实在在的优势，一定要写上。

### 照片和出生日期

很多海湾和埃及的雇主仍然希望看到照片，尤其是需要面对客户的岗位。跨国公司则越来越倾向于不带照片的简历，有些 ATS 系统也处理不好图片。出生日期的趋势相同：以前几乎人人都写，现在常常等到填写申请表时才提供。

## 学历、成绩和认证

写明学位、专业、学校、国家和毕业年份。海湾的招聘人员不一定熟悉中国的大学，加上"中国"和一句简短说明会有帮助，比如"985 工程"这种说法外国人看不懂，可以改成"one of China's leading research universities"。工作几年之后，绩点可以不写；如果要写，就用学校本身的计分方式，比如"GPA 3.6/4.0"或"平均分 86/100"，不要自己换算。

### 学历认证和学历等同

大多数海湾国家在签发工作签证或工作许可之前，会要求对学历证书进行认证。流程通常要经过颁发学历的国家的有关部门，再到目标国家的使领馆或外交部门。根据目标国家的不同，可能办理附加证明书即可，也可能需要领事认证。有些国家对特定职位还要求当地教育部出具学历等同证明，尤其是医疗、教育和政府部门。具体步骤因国家和职业而异，也会不时调整，请向雇主或相关使领馆确认最新流程。

如果认证已经完成，在学历下面加一行即可，例如"Degree attested for UAE employment"。这能让雇主放心，录用不会因为手续拖延。如果还没开始办理，就不要写，但如果你是认真考虑赴海湾工作，最好尽早着手。

## 职业执照和资格

在海湾地区，很多职业在开始工作之前需要取得当地的执照或注册。护士、医生和其他医疗人员通常需要从所在国家或酋长国的卫生主管部门取得执照，往往还要通过考试，并由原发证机构核实证书。在沙特，工程师需要在沙特工程师理事会注册。会计人员如果持有注册会计师、ACCA 或 CMA 等资格，请写明全称和取得年份。国内的职称，比如"高级工程师"，可以写成"Senior Engineer (professional title, China)"，并说明这是职称而不是职位。

如果你已经取得海湾地区的执照或通过了考试，请放在简历靠上的位置。如果申请还在审核中，请如实写明："DHA license application under review"。护理人员可以参考[注册护士简历模板](/zh/templates/registered-nurse)，里面为执照编号和有效期留有专门的位置。

## 沙特化和阿联酋化

所有海湾国家都有提高本国公民在私营部门就业比例的政策：沙特的"沙特化"（Nitaqat），阿联酋的"阿联酋化"，以及卡塔尔、科威特、巴林和阿曼的类似计划。在沙特，有些职位只限本国公民担任，企业需要根据行业和规模达到一定的本地雇员比例。

实际影响是：有些招聘广告只面向本国公民。但工程技术、医疗、建筑和技术类岗位仍然大量招聘外籍人员。请仔细阅读招聘广告，不要把时间浪费在只招本国公民的职位上。

## 期望薪资

不要把薪资写在简历上。简历会在不同公司之间流转好几个月，适合一家公司的数字，可能会让你在另一家被淘汰。如果申请表要求填写，就给出一个实际的范围。

海湾地区的薪酬通常由基本工资加上住房补贴和交通补贴组成，有时还包括每年的回国机票、子女教育补贴和医疗保险。服务期满后的离职补偿金往往只按基本工资计算，所以请说明你说的是基本工资还是总薪酬。不要把国内的税前年薪直接换算成迪拉姆或里亚尔来比较，因为税收和生活成本差别很大。报数字之前，先了解你所在职位在该国家的一般薪资水平。

## 篇幅和板块顺序

应届毕业生和工作经验较少的人，一页就够了。工作经历较长，或者执照和证书较多的人，两页也可以。建议顺序如下：

1. 姓名、目标职位和联系方式，电话号码带国际区号
2. 简短的个人信息：国籍、所在地或签证、离职通知期
3. 两三句话的个人简介
4. 工作经历，从最近的写起
5. 教育背景
6. 执照、证书和会员资格
7. 技能
8. 语言能力，注明每种语言的水平

每一条工作经历都用动词开头，能写结果就写结果。"负责财务工作"这种写法很弱，"每月完成十二个银行账户的对账，把月结时间从十天缩短到六天"就清楚得多。可以参考[会计简历模板](/zh/templates/accountant)的写法。

## 招聘网站和领英使用习惯

在海湾地区，人们通常同时通过多个渠道找工作：

- **地区性招聘网站**：有的覆盖整个海湾地区，有的只针对一个国家。很多网站除了上传简历，还要求填写个人资料，请保持两者一致。
- **领英（LinkedIn）**：在阿联酋、沙特和卡塔尔，办公室、技术和管理类职位大量使用领英。招聘人员会直接在上面搜索，所以请用英文写清楚职位头衔，并填写所在地或目标国家。
- **猎头和招聘公司**：在医疗、工程、酒店和销售领域作用很大。
- **内部推荐**：前同事和当地朋友的推荐在这个地区很有分量。当地的中资企业商会和华人专业人士圈子也常常有职位信息。

对于要求你为工作或签证付费的机会，一定要提高警惕。正规雇主不会向求职者收取招聘费用。

## 常见错误

- 申请海湾职位却不写国籍、所在地和离职通知期
- 写上政治面貌、身份证号或护照号
- 把机器翻译的简历不经检查直接发出
- 在简历上写薪资
- 以为国内的执照可以在海湾直接上岗
- 电话号码没有国际区号
- 发送一个名叫"简历最终版新"的 Word 文件

## 发送前检查清单

- 简历的语言和招聘广告一致
- 国籍、所在地或签证、离职通知期写在清楚的一行里
- 学历写明学校和国家，如果已经完成认证也注明了
- 如果职业需要，执照和注册信息放在靠上的位置
- 简历上没有薪资
- 文件是 PDF，文件名包含姓名和职位，例如"Wang-Lei-Mechanical-Engineer.pdf"
